# 手動レビュー用プロンプト

対象PRの最新headを取得し、次を日本語でレビューしてください。レビュー開始時にPR番号、現在のhead SHA、PR本文、全差分、最適化解析資料、関連CIの状態とリンク、PRの過去レビュー指摘を確認してください。過去の指摘ごとに現在も該当するかを再評価し、新規指摘も確認します。

対象は `function_call_numeric_sum` のC・Python・JavaScript最適化解析です。3ソースのSHA-256、処理系と版、アーキテクチャ、コンパイル／起動オプション、各保存資料から抽出したmanifestのfindingsが一致するか確認してください。JITは処理系への搭載・起動設定・対象コードでの実作動を区別し、インライン化・ベクトル化・SIMDは対象コードを示す証拠を確認してください。条件不一致や証拠不足を測定時間から補わず、スキーマに沿って降格すべきか確認してください。新CPU診断や測定、ベンチマーク条件変更は提案しないでください。

各指摘には必ず次を記載してください。

- 対象head SHA
- ファイルと行、または資料内の位置
- 重要度
- 問題の理由と根拠
- 再現・確認方法
- 具体的な修正方針

指摘がなければ、そのhead SHAで必要なCIが成功しているか、PR本文に記録されたhead SHAとCIリンクが一致しているかを明記してください。headがレビュー中に変わった場合は、そのレビューを完了扱いにせず、新headでPR本文、全差分、資料、CI、過去指摘を再確認してください。
